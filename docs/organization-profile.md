### 我们在探索什么

**Open Robot Agent（ORA）** 是一个面向通用具身智能的持续研究项目。我们关注如何将通用语言、视觉推理及软件工具能力拓展到机器人所处的物理世界，让 Agent 不只会生成行动指令，也能在可信的执行与观测闭环中理解行动结果。

<table>
<tr>
<td width="33%" valign="top">

**01 · 通用智能**

基于统一的多模态 Agent，将环境感知、空间推理、长期规划与操作决策联系起来。

</td>
<td width="33%" valign="top">

**02 · 可信执行**

由 Harness 连接模型与机器人能力；运动学、规划、权限及物理安全由可信系统负责。

</td>
<td width="34%" valign="top">

**03 · 闭环反馈**

用真实观测与执行结果检验行动，而不是将模型预测或控制器返回值直接当作任务成功。

</td>
</tr>

### 通用 Robot Agent 的能力图谱

| 通用智能底座 | 面向物理世界的六类能力 |
| :-- | :-- |
| 目标理解与长期规划 | **感知与空间理解** · 识别目标、位置和三维关系 |
| 推理、记忆与软件工具 | **物体操作理解** · 选择接触位置和操作方式 |
| 自适应推理与人机协作 | **物理工具使用** · 理解并运用真实世界中的工具 |
| | **物理推理与预测** · 理解接触、后果与不确定性 |
| | **本体行动规划** · 选择机器人及适合的行动抽象 |
| | **反馈与调整** · 主动观察、验证、恢复与重新规划 |

> [!NOTE]
> **这是一幅长期研究能力图谱，不是已实现功能清单。** ORA 目前仍处于研究和原型迭代阶段，具体实现与验证状态不能由该图推断。

### 研究方向

<div align="center">

**可信机器人交互** &nbsp;→&nbsp; **可验证的真实经验** &nbsp;→&nbsp; **更通用的物理智能**

</div>

我们重视能够复现的证据、真实物理反馈、跨机器人泛化，以及推理与行动的效率。研究想法是否有效，最终应由严格的实验与实际闭环表现来判断。

<summary><b>English overview</b></summary>

**Open Robot Agent (ORA)** is an ongoing research initiative exploring how general-purpose multimodal intelligence can interact reliably with the physical world.

Our long-term direction connects **general reasoning**, **embodied perception and manipulation**, **trusted robotic execution**, and **observation-grounded feedback**. We aim to study how verifiable physical interaction experience may support more general and efficient embodied capabilities.

This is a research vision, **not a claim that all listed capabilities have been implemented or validated**. Core research code and unpublished methods remain private for now.

Explore the [project website](https://openrobotagent.github.io/) for the public overview.
